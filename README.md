# PDF Utils

Convertitore Win32 nativo batch JPG/JPEG → PDF e PDF → PDF/A-2b con interfaccia grafica, progettato per Windows 7 SP1 e Windows 11 (x86/x64).

Il progetto include motore JPEG che genera PDF A4 senza ricompressione e supporto Ghostscript per PDF/A-2b. La conversione PDF/A richiede Ghostscript installato separatamente.

Le due versioni Windows sono compilate senza .NET, Java, Python o runtime VC++ e hanno subsystem minimo Windows 7 (6.1). L'interfaccia non è ancora stata testata su macchine Windows reali; la compatibilità va verificata sul sistema di destinazione.

Consultare la documentazione e i sorgenti nel pacchetto di distribuzione fornito nella conversazione di sviluppo. Il progetto non include Ghostscript, che è soggetto a licenza AGPL/commerciale.
